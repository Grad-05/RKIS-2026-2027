## Описание
Консольное приложение для управления списком задач, разработанное в рамках лабораторных работ. 
В программе реализован личный профиль пользователя, а также полноценный менеджер задач с возможностью добавления, редактирования, удаления и отметки задач как выполненных.
При запуске программа запрашивает имя, фамилию и год рождения пользователя, вычисляет возраст и переходит в режим ввода команд.
## Программа поддерживает следующие команды:
* help — выводит список всех доступных команд с кратким описанием.
* profile — выводит данные пользователя в формате: <Имя> <Фамилия>, <Год рождения>.
* add "текст задачи" — добавляет новую задачу в список. Текст задачи нужно писать в кавычках. 
* view — выводит все добавленные задачи (выводятся только непустые элементы).
* done <индекс> — отмечает задачу выполненной .
* delete <индекс> — удаляет задачу по указанному индексу (все элементы после неё сдвигаются влево).
* update <индекс> "новый текст"` — обновляет текст задачи (дата изменения обновляется).
* exit — завершает цикл и закрывает программу.
